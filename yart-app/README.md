# yart-app

The YART desktop app. See the [README in the repository root](../README.md) for what
it does and how to connect an agent.

```bash
npm install
npm run dev     # the app with hot reload
npm run check   # typecheck, lint, format check and tests
```

`demo/todo-app` is a small app to analyse. Commands, architecture and code style are
described in [CLAUDE.md](CLAUDE.md).
